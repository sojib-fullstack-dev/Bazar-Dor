# 🛒 বাজার দর | BazarDor

প্রয়োজনীয় পণ্যের দাম এক নজরে। BazarDor is a responsive web application for exploring daily essential product prices in Bangladesh.

## 🌐 Live Website

https://bazar-dor-web-bd.vercel.app/

## 🛠️ Technologies Used

* Next.js
* TypeScript
* Tailwind CSS
* Better Auth

## ✨ Key Features

1. **Daily Price Tracking** — View daily prices of essential products.
2. **Price Changes** — Explore products with increased and decreased prices.
3. **Category Filtering** — Browse products by category.
4. **Product Details** — View product information and market-wise prices.
5. **Authentication** — Sign in, sign up, and manage user profile.
